# create-report

퀴즈 결과에 대한 상대 평가 등급 리포트를 생성합니다.

## 사용법

```
/create-report
```

## 절차

localStorage에 저장된 순위 데이터를 분석하여 리포트를 생성한다.

## 리포트 내용

### 1. 기본 통계

- 총 참여자 수
- 평균 점수
- 최고 점수 / 최저 점수
- 모드별 참여 현황

### 2. 상대 평가 등급

점수 분포에 따른 등급 부여:
- A (상위 10%): 우수
- B (상위 30%): 양호
- C (상위 60%): 보통
- D (상위 90%): 미흡
- F (하위 10%): 노력 필요

### 3. 참여자별 결과

이름, 점수, 모드, 등급을 테이블로 정리

## 출력 형식

```
📊 퀴즈 결과 리포트
━━━━━━━━━━━━━━━━━━━━━━
생성일: 2026-11-20

기본 통계:
  참여자: 8명
  평균: 72점
  최고: 100점 (홍길동)
  최저: 40점

등급 분포:
  A: 1명 (12.5%)
  B: 2명 (25.0%)
  C: 3명 (37.5%)
  D: 2명 (25.0%)

상세 결과:
| 순위 | 이름 | 점수 | 모드 | 등급 |
|------|------|------|------|------|
| 1 | 홍길동 | 100 | 일반 | A |
```
