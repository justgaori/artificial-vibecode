# quiz-add

검증 규칙을 지킨 새 퀴즈 한 문항을 questions.js에 추가합니다.

## 사용법

```
/quiz-add <분야> <난이도>
```

## 인수

- 분야: 한국사, 과학, 지리, 예술과 문화 중 하나
- 난이도: 초급 또는 중급

## 절차

1. `.cursor/rules/quiz.mdc`의 검증 규칙을 따른다.
2. 교과서나 널리 확인되는 사실 하나만 고른다.
3. 최상급이 들어가면 측정 기준을 `criteria`에 적는다.
4. 보기 4개와 해설을 만들고, `answer`는 정답 인덱스다.
5. `quiz/questions.js`의 배열 맨 끝에 다음 id로 추가한다.
6. 추가한 문항의 질문, 정답, 기준을 짧게 보고한다.

## 주의사항

- 확인되지 않는 연도나 순위는 만들지 않는다.
- 정답 인덱스(0~3)가 기존 문항과 균형을 이루도록 한다.
