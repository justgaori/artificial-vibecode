# quiz-daily

퀴즈 데이터의 일일 점검을 통합 실행합니다.

## 사용법

```
/quiz-daily
```

## 절차

다음 명령을 순서대로 실행하고 결과를 종합 보고한다.

### 1. 구조 파악

`/quiz-check` 실행하여 데이터 무결성 확인

### 2. 분포 확인

`/quiz-range 1 32` 실행하여 전체 정답 분포 확인

### 3. 최상급 검증

`/quiz-validate` 실행하여 기준 없는 최상급 확인

### 4. 중복 확인

같은 question 문자열이 있는지 확인

### 5. 백업 생성

`quiz/backup/` 폴더에 `questions_YYYYMMDD.js` 형식으로 백업
(폴더가 없으면 생성)

### 6. 리포트 생성

검사 결과를 종합한 마크다운 리포트 출력

## 출력 형식

```
📋 퀴즈 일일 점검 리포트
━━━━━━━━━━━━━━━━━━━━━━━━━━
일시: 2026-11-20

✅ 구조 검사: 통과 (32개 문항)
⚠️ 정답 분포: 인덱스 3 부족 (0개)
✅ 최상급 검증: 통과
✅ 중복 확인: 없음
✅ 백업: quiz/backup/questions_20261120.js

권장 조치:
1. 정답 인덱스 3을 사용하는 문항 추가 필요
```
