# quiz-range

지정한 번호 구간의 난이도와 정답 분포를 분석합니다.

## 사용법

```
/quiz-range <시작> <끝>
```

## 인수

- 시작: 분석 시작 문항 id
- 끝: 분석 종료 문항 id

## 절차

`quiz/questions.js`의 `QUIZ_BANK`에서 id가 시작 이상 끝 이하인 문항만 분석한다.

## 출력 내용

1. 문항 수, 분야별 개수, 초급/중급 개수
2. 정답 인덱스 0, 1, 2, 3이 각각 몇 번인지
3. 한 보기에 정답이 절반을 넘으면 그 사실을 알리고, 어느 문항의 정답 위치를 바꾸면 고를지 제안한다
4. 같은 분야가 연속으로 네 문제 이상이면 그 구간을 표시한다

## 주의사항

- 문제를 삭제하거나 사실을 바꾸라는 제안은 하지 않는다.
- 정답 위치만 이야기한다.
