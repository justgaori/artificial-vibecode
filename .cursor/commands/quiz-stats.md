# quiz-stats

퀴즈 데이터의 통계를 보여줍니다.

## 사용법

```
/quiz-stats
```

## 절차

`quiz/questions.js`의 `QUIZ_BANK`를 읽어 통계를 계산한다.

## 출력 내용

### 기본 통계

- 총 문항 수
- 분야별 문항 수 (한국사, 과학, 지리, 예술과 문화)
- 난이도별 문항 수 (초급, 중급)

### 정답 분포

- 정답 인덱스별 개수 (0, 1, 2, 3)
- 편향 경고: 한 인덱스에 25% 이상 차이나면 경고

### criteria 현황

- criteria가 있는 문항 수
- 최상급 표현이 있지만 criteria가 없는 문항 목록

## 출력 형식

```
📊 퀴즈 통계
━━━━━━━━━━━━━━━━━━━━
총 문항: 32개

분야별:
  한국사: 8개 (25%)
  과학: 8개 (25%)
  지리: 8개 (25%)
  예술과 문화: 8개 (25%)

난이도별:
  초급: 16개 (50%)
  중급: 16개 (50%)

정답 분포:
  인덱스 0: 8개 (25%)
  인덱스 1: 8개 (25%)
  인덱스 2: 8개 (25%)
  인덱스 3: 8개 (25%)
```
