# quiz-validate

퀴즈에서 기준 없는 최상급 표현을 찾습니다.

## 사용법

```
/quiz-validate [분야]
```

## 인수

- 분야 (선택): 한국사, 과학, 지리, 예술과 문화 중 하나. 없으면 전체 검사.

## 분야 매핑

- 한국사 → `history`
- 과학 → `science`
- 지리 → `geo`
- 예술과 문화 → `art`

## 절차

`quiz/questions.js`의 `QUIZ_BANK`를 읽어 검사한다.

## 출력 내용

1. 문제 문장에 '가장', '최초', '최대', '최고', '최장'이 있는데 `criteria`가 없는 문항
2. 해설 없이 순위를 단정한 문항
3. 고칠 문장 초안. 기준을 문제 안에 넣고, 논쟁이 있으면 해설에 남긴다

## 주의사항

- 파일을 바로 고치지 말고, 목록을 먼저 보여 준 뒤 수정을 요청받으면 `quiz/questions.js`만 수정한다.
