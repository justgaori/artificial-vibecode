## 기록 작성 가이드

1. **날짜**: 작업한 날짜를 YYYY-MM-DD 형식으로 기록
2. **프롬프트**: AI에게 요청한 구체적인 내용 (실제 입력한 텍스트 또는 요약)
3. **AI 응답 요약**: AI가 제안한 코드, 설명, 해결책의 핵심 내용
4. **검토·수정**: 
   - AI 응답을 그대로 사용했는지, 수정했는지
   - 수정했다면 어떤 부분을 왜 수정했는지
   - 오류가 있었다면 어떻게 발견하고 고쳤는지
5. **결과**: 최종적으로 반영된 변경 사항

### 좋은 기록 예시

- ❌ "AI가 코드를 만들어 줬다" (너무 추상적)
- ✅ "AI가 localStorage 저장 로직을 제안했으나, 키 이름이 기존과 충돌하여 'quiz-rank.v2'로 변경" (구체적)

### 포함하면 좋은 내용

- AI가 잘못된 정보를 제공한 경우와 수정 과정
- AI 제안을 거부하고 다른 방식을 선택한 이유
- 여러 번의 프롬프트 수정으로 원하는 결과를 얻은 과정
