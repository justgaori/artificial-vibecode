# 프로젝트 설명 및 주요 기능

- 프로젝트명: 기숙사 공용 세탁실 "지금 빈 세탁기" 확인·알림 서비스
- 작성자: 김가온 · 223902
- 근거 문서: 휴먼 컴퓨터 워크북 03 제안서, 04 사용자 연구계획, 05 맥락질의, 06 작업분석·어피니티
- 형태: 한국어 모바일 웹. 상태 데이터는 시뮬레이션

## 목적

국립목포대학교 생활관 학생이 세탁실에 내려가기 전에 "지금 간다 / 조금 뒤 간다 / 미룬다"를 정하게 하는 것이 목적입니다. 기획서의 문제는 빈 기기를 미리 알 수 없어 바구니를 들고 내려갔다가 돌아오는 헛걸음, 그리고 종료 시각을 휴대폰 타이머로 매번 직접 맞추는 일이었습니다.

기획서의 목표 문장은 그 확인과 알림 설정을 60초 안에, 알림 설정은 힌트 없이 한 번에 끝나게 하는 것이었습니다. 이 결과물은 그 화면 흐름을 클릭만으로 끝까지 수행할 수 있게 만들었습니다. 사용성 테스트 점수 자체를 대신 측정하지는 않습니다.

## 누구를 위한 화면인가

생활관에 사는 학생입니다. 관리자 화면, 고장 신고, 결제, 다국어, 실제 IoT 연동은 제안서의 제외 범위라 넣지 않았습니다.

## 주요 기능

1. **가기 전 판단.** 홈 맨 위에 바로 가능 대수, 가장 빨리 끝나는 시간, 회수 대기 대수를 보여 줍니다. 그 아래 결정 카드가 "지금 시작 / 끝나면 알림 / 오늘은 미룸" 중 하나를 고르게 합니다. 가장 빠른 기기가 15분 이하면 기다릴 만한 시간으로, 그보다 길면 갔다가 다시 올라오기 쉬운 시간으로 안내합니다. 이 15분 기준은 05·06의 P01 진술을 따른 것입니다.
2. **종료 알림 1회 예약.** 빈 기기를 열면 표준 코스와 **+5분**이 이미 선택되어 있습니다. **종료 알림 예약하고 시작**을 한 번 누르면 예약이 끝납니다. 정시도 고를 수 있습니다. +5분이 기본인 이유는, 표시 시각에 맞춰 가면 아직 돌고 있던 경험과 너무 늦으면 다른 사람이 빨래를 꺼내는 문제 사이의 절충으로 06에서 정리되었기 때문입니다.
3. **회수 대기와 회수 알림.** 끝난 기기에 빨래가 남아 있으면 회수 대기로 표시합니다. 누구의 빨래인지는 보이지 않습니다. 내 세탁이 끝난 뒤 찾아가지 않으면 회수 알림이 한 번 더 옵니다. 다른 사람 화면 문구는 "회수 대기"뿐입니다.
4. **즐겨 찾는 동.** 설정에서 A·B·C동을 저장합니다. 동마다 남은 시간이 조금 다르게 보여, 어느 동을 볼지 고르는 의미가 있습니다.
5. **상황과 배속.** 센서가 없으므로 저녁 혼잡, 자리 있음, 회수 대기 세 상황을 불러올 수 있습니다. 발표에서 알림까지 바로 보려면 120배속을 켭니다.

알림은 앱 안 알림함이 기본입니다. 브라우저가 허용하면 휴대폰 알림도 함께 띄웁니다. 권한을 거절해도 알림함은 동작합니다.

## 기획 요구와 화면

| 기획 요구 | 화면 |
|---|---|
| 홈 첫 화면에 바로 가능 / 가장 빨리 / 회수 대기 | 홈 상단 세 칸 |
| 지금 간다, 몇 분 뒤 간다, 미룬다 | 결정 카드의 시작·알림·미루기 |
| 끝나는 기기를 예약하면 "지금 내려가면 됩니다" | 알림함의 종료 알림. 다른 사람 기기는 회수 대기로 바뀌면 그 사실도 알림 |
| 세탁 시작 시 종료 알림을 1탭, 시점은 정시 또는 +5분 | 빈 기기 화면. 기본값 +5분, 버튼 하나 |
| 회수가 늦으면 알림 1회, 다음 사람에게는 식별 정보 없이 회수 대기 | 종료 알림 10분 뒤 회수 알림. 기기 행에는 이름·호실 없음 |
| 상태 데이터는 시뮬레이션 | 화면 하단 안내, 설정의 상황·배속 |
| 관리자, 고장 신고, 결제, 다국어, IoT 제외 | 해당 화면 없음 |

## 화면 구성

- 홈: 판단 숫자, 결정, 세탁기·건조기 목록
- 기기: 시작, 종료 알림 예약, 회수 대기 설명
- 내 세탁: 남은 시간, 알림 시점, 빨래를 찾았어요
- 알림: 예약·종료·회수 기록
- 설정: 동, 상황, 배속, 알림 권한, 처음 상태로 되돌리기

## 기술

별도 설치나 빌드 없이 브라우저만으로 실행되는 정적 페이지입니다. 동, 알림, 진행 중인 세탁은 이 브라우저의 `localStorage`에 저장됩니다. 서버나 계정은 없습니다.

## 한계

- 숫자는 기획 검증용 시뮬레이션이라 생활관 세탁기의 실제 상태와 같지 않습니다.
- 05의 P01 기록과 06의 인사이트는 문서에 적힌 대로 예상 분석입니다. 이 웹은 그 문서를 화면으로 구현한 것이고, 새로운 사용자 조사 결과를 넣지는 않았습니다.
- 여러 명이 동시에 같은 알림을 받고 내려가는 경쟁은 1인 화면에서 재현하지 않았습니다. 06의 To-be에 적힌 위험으로 남아 있습니다.
