# [중요과제] 지금 빈 세탁기

김가온 · 223902

생활관 공용 세탁실에서 **가기 전에** 빈 기기, 가장 빨리 끝나는 시간, 회수 대기를 보고 종료 알림을 예약하는 모바일 웹입니다. 기획 문서 03~06의 화면 흐름을 동작하는 결과물로 만든 폴더입니다.

기기 상태는 센서 없이 만든 시뮬레이션입니다. 실제 세탁기와 연결되어 있지 않습니다.

## 폴더

| 파일 | 내용 |
|---|---|
| `app/` | 실행 가능한 소스. `index.html`, `styles.css`, `app.js` |
| `01_프로젝트_설명.md` | 목적, 주요 기능, 기획과의 대응 |
| `02_프롬프트_기록.md` | 이번 구현에서 사용한 지시와 고친 과정 |

## 실행

`app/index.html`을 브라우저로 열면 됩니다. 주소가 `file://`로 시작해도 동작합니다.

터미널에서 실행하려면 `app` 폴더에서 아래를 입력합니다.

```powershell
python -m http.server 8766
```

브라우저에서 `http://127.0.0.1:8766/` 을 엽니다. 화면은 휴대폰 너비에 맞춰져 있고, 넓은 화면에서는 가운데에 휴대폰 프레임으로 보입니다.

## 확인 순서

1. 처음 화면은 **저녁 혼잡**입니다. 바로 가능 0대, 가장 빨리 7분, 회수 대기 1대인지 확인합니다.
2. **끝나면 알려 주세요**를 누르고, 알림 탭에 예약이 생기는지 확인합니다.
3. 세탁 4처럼 **회수 대기**인 기기는 이름·호실 없이 "지금은 쓸 수 없다"고 나오는지 확인합니다.
4. 설정에서 **자리 있음**으로 바꾸면, 빈 기기에서 **표준 / +5분**이 이미 선택된 채로 **종료 알림 예약하고 시작** 한 번으로 세탁이 시작됩니다.
5. 끝나는 알림과 회수 알림을 바로 보려면 설정에서 **120×**로 바꿉니다. 표준 코스는 약 24초 뒤에 끝나고, 5분 늦은 알림과 10분 뒤 회수 알림이 이어집니다.
6. **빨래를 찾았어요**를 누르면 그 기기는 다시 빈 기기가 됩니다.

기본 배속은 1×입니다. 7분이라는 숫자가 바로 줄어들지 않게 하기 위해서입니다.
