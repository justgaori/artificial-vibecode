## 주요 의사결정 기록

### 채점 방식 선택

**문제**: JavaScript 코드를 안전하게 실행하는 방법

**고려한 대안**:
1. 서버 사이드 실행 (Node.js sandbox)
2. 브라우저 Web Worker
3. 외부 채점 서비스 (Judge0)

**선택**: 브라우저 Web Worker

**이유**:
- 별도 서버 설정 불필요
- 브라우저 샌드박스로 안전한 실행 보장
- 타임아웃 설정 용이
