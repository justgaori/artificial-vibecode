분야와 난이도는 $ARGUMENTS 이다. 분야는 한국사, 과학, 지리, 예술과 문화 중 하나이고 난이도는 초급 또는 중급이다.

`CLAUDE.md`의 검증 규칙을 따른다.

1. 교과서나 널리 확인되는 사실 하나만 고른다.
2. 최상급이 들어가면 측정 기준을 `criteria`에 적는다.
3. 보기 4개와 해설을 만들고, `answer`는 정답 인덱스다.
4. `questions.js`의 배열 맨 끝에 다음 id로 추가한다.
5. 추가한 문항의 질문, 정답, 기준을 짧게 보고한다.

확인되지 않는 연도나 순위는 만들지 않는다.
